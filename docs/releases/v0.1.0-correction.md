# `v0.1.0` GPL compliance correction

Status: **documented, awaiting a human with release rights.** This file does
not rewrite the published tag or the published release history.

## What was wrong

The `v0.1.0` release (2026-10-28) published seven desktop installers and a
checksum manifest. The release body had no corresponding-source statement, and
the tagged source tree had no root `LICENSE`, no modification notice, and only
the mosh and EternalTerminal license files under `resources/`. The release body
mentioned "license notices", but the application's own GPL text and complete
third-party notices were absent.

The application is a GPL-3.0-or-later derivative of
[binaricat/Netcatty](https://github.com/binaricat/Netcatty). The omission is a
distribution compliance defect; it does not change the license that already
applied to the code.

## What this repository now provides

The compliance commit on `desktop-mosh-et` adds:

- root `LICENSE` (GNU GPL version 3 text) and root `NOTICE` (GPL-3.0-or-later,
  modification notice, copyright statement, and source offer);
- the completed `resources/THIRD-PARTY-NOTICES.md`;
- the in-app **Settings → About & Licenses** surface;
- a per-release `SOURCE-OFFER.md` generated by
  `internal/tools/sourceoffer` and carried in every package;
- the `internal/legal` Go tests, which fail when a document is missing.

### Option A: correct the existing release assets and body

From a checkout of the compliance commit, with an account that can edit the
release:

```sh
# 1. Write the exact source offer for v0.1.0.
go run ./internal/tools/sourceoffer -version 0.1.0 \
  -out SOURCE-OFFER-v0.1.0.md

# 2. Start from the published body, append the corrective statement below and
#    the source offer, then replace the release body.
gh release view v0.1.0 --json body --jq .body > RELEASE_NOTES-v0.1.0.md
cat SOURCE-OFFER-v0.1.0.md >> RELEASE_NOTES-v0.1.0.md
gh release edit v0.1.0 --notes-file RELEASE_NOTES-v0.1.0.md

# 3. Attach the license, notices, source offer, and this correction document.
gh release upload v0.1.0 LICENSE NOTICE \
  resources/THIRD-PARTY-NOTICES.md SOURCE-OFFER-v0.1.0.md \
  docs/releases/v0.1.0-correction.md --clobber
```
