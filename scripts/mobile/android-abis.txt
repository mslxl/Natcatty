# The Android ABIs natcatty ships, in the order the build gate walks them.
#
# This file is the single list the compile gate (scripts/mobile/check-compile.sh),
# the archive staging script (scripts/mobile/android-libs.sh) and the
# architecture test (internal/archtest) read. MyGo's cmd/mygo/android.go ships
# the same three androidABIs; keep them in step.
#
# Columns:
#   abi         the jniLibs directory and the device's ro.product.cpu.abi
#   goarch      GOARCH for the Go toolchain (arm needs GOARM=7)
#   triple      the NDK compiler triple, before the API level
#   artifact    the key in ui/terminal/artifacts.json for the pinned archive
#   elf-class   the archive's ELF class
#   elf-machine the machine name llvm-readelf -h reports
#
# armeabi-v7a is a deliberate product decision: the project keeps the 32-bit
# ARM ABI alongside arm64-v8a and x86_64.
arm64-v8a   arm64 aarch64-linux-android        android-arm64-v8a   ELF64 AArch64
armeabi-v7a arm   armv7a-linux-androideabi     android-armeabi-v7a ELF32 ARM
x86_64      amd64 x86_64-linux-android         android-x86_64      ELF64 X86-64
